# Architecture review

Present a small number of viable options, a recommendation, and the reason for it. Make tradeoffs explicit, especially for Blazor hosting, Philips Hue API version/connectivity, AI provider abstraction, structured intent versus tool calling, secrets, and testability. Keep the first version modular but not over-engineered. Record decisions as short ADRs with context, decision, and consequences; ask the user before treating a consequential assumption as final.
